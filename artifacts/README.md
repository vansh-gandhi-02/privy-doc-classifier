# artifacts/: cached results (about 30 MB)

Things that are slow, need a Claude subscription, or must never be re-run, so the notebook and `scripts/run_all.py` can replay them:

- `sample/text.jsonl`: the reading ladder's text for every dev-sample document (about an hour of OCR on 6 cores)
- `sample/pages.npz`: DiT features of every dev-sample page
- `sample/labels.csv`, `manifest.csv`: the dev sample's labels and manifest (the documents themselves are regenerated by `docgen`)
- `sample/l3_calls.jsonl`: every LLM answer, made through `claude -p` on a Claude subscription. Replayed, never re-asked; to classify new documents with the LLM step you need your own subscription or API key.
- `sample/timing_samples.json`, `bench.json`: the measured CPU time of every step
- `lockbox_*/final_*`: each sealed test set's single run (D15, D27, D29, D30). Not re-run, by design.
- charts and the contact sheet (one sample of each generated document type)

`python -m tools.artifacts unpack` copies them into `data/`.
