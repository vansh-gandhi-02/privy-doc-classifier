\section{The idea}
\begin{itemize}
\item \textbf{Every document carries a probability for each class,} starting from the class mix expected for its file format (never zero).
\item \textbf{Evidence is bought cheapest first:} metadata, page layout, a few lines of text, the full page, then an LLM. Each step updates the probabilities (Bayes).
\item \textbf{A document stops as soon as one class reaches 95\%;} otherwise it buys the cheapest next step that can still separate the classes in play.
  \begin{itemize}
  \item A sequential test (Wald's SPRT, many-class form): money goes only where the evidence so far cannot decide.
  \end{itemize}
\item \textbf{A budget controller moves the gate ($\tau$) mid-run} when spend trends over or under plan.
\end{itemize}

\section{What we assumed}
\begin{itemize}
\item \textbf{15 classes.} The brief lists 15 and mentions ``25'' once; we read that as a leftover.
\item \textbf{Critical: Legal, Property, Proof of Identity (PoI), Proof of Address (PoA).} No class is medical; in a bank, ``regulatory'' means KYC.
\item \textbf{Class mix per format:} from typical bank collections; reproduces the brief's format split within 0.03 points. KYC is 20\%.
\item \textbf{Class boundaries:}
  \begin{itemize}
  \item An ID with a visible address is PoA, otherwise PoI; PAN is always PoI.
  \item Anything that transfers, mortgages, titles or values property is Property; every other agreement, rent included, is Legal.
  \item Passbooks are not bank statements (labelled Other). An email takes its attachment's class.
  \end{itemize}
\item \textbf{One file can hold several documents} (merged PDFs); each is classified with its page range.
\item \textbf{Prices:} the brief's rates; a cloud vCPU taken as 2x slower than our laptop core.
\item \textbf{People:} the brief quotes no price for human review, so it is counted, not costed.
\item \textbf{Margin:} we target \R50k of compute (50\% margin) with a 10\% reserve, so the controller aims at \R45k.
\item \textbf{Test data:} synthetic documents for all 15 classes (no real customer data), plus public Indian bank statements (AgamiAI).
\end{itemize}

\section{How a document moves, cheapest step first}
\begin{itemize}
\item \textbf{L0, open the file} (\N{l0-ms} ms): true type, visible text or scan, emails and zips unpacked. Same checksum as an earlier file: copy its label.
\item \textbf{L1, layout} (\N{l1-s} s a page): a frozen document-vision model (DiT) plus six readable signals (page shape, QR code, photo).
  \begin{itemize}
  \item Settles \N{l1-settles} of scans, all correctly. A passbook and a statement share words, not layout.
  \end{itemize}
\item \textbf{L2, text:} free text first (1 ms); for scans, the top and largest lines (\N{sel-s} s), then the full page (\N{full-s} s), then the next and last pages.
  \begin{itemize}
  \item A word counts only if it is likelier under one remaining class than another, so shared words cancel out.
  \item Checksum-valid IDs (Aadhaar, PAN, GSTIN) are evidence, not verdicts: a loan form quotes a PAN too.
  \item Legal and property files open with the same e-stamp page, so they read their later pages first.
  \end{itemize}
\item \textbf{Address question} (KYC cards, one full read): a valid PIN code plus an address label or state means PoA, otherwise PoI.
\item \textbf{L3, LLM} (\R\N{llm-call} a call): Claude Haiku sees masked text and only the 2 to 5 classes in play plus ``none of these''.
  \begin{itemize}
  \item It quotes the deciding words, then answers; the answer is weighed by its measured error rate, not taken as the verdict.
  \end{itemize}
\item \textbf{L4, a person:} whatever is still below 95\% after the LLM.
\item \textbf{Two safeguards:}
  \begin{itemize}
  \item \lab{Critical safety net:} a document with a 10\% or higher chance of a critical class keeps a 95\% gate, whatever the controller does.
  \item \lab{Merged PDFs:} split page by page; ``Page 3'' cannot start a document, ``Page 1'' always does.
  \end{itemize}
\end{itemize}

\section{Why the gates sit where they do}
\begin{itemize}
\item \textbf{95\% to accept:} an accepted document is wrong at most 5\% of the time (measured: \N{settled-acc} right). Each step costs several times the last, so stopping early is the cheapest path to the bar.
\item \textbf{$\tau$, moved by the controller between 85\% and 99\%,} applies to every gate before the LLM, because reading pages is where the money goes.
  \begin{itemize}
  \item Measured at 5M: $\tau$ 0.85 costs \R\N{t85-cost} at \N{t85-acc} accuracy; 0.95, \R\N{t95-cost} at \N{t95-acc}; 0.99, \R\N{t99-cost} at \N{t99-acc}. Above 95\% buys nothing, so it holds 95\%.
  \item Squeezed to \R23k with a scan-heavy stretch, it lowered $\tau$ to \N{stress-tau} and spent \R\N{stress-spent}, against \R\N{stress-fixed} without it.
  \item The 85\% floor is a judgement call: at 80\%, too many wrong labels get through for a bank.
  \end{itemize}
\item \textbf{LLM effort, by a rule fixed in advance:} the cheapest mode whose accuracy clears 95\% at the lower 90\% confidence bound.
  \begin{itemize}
  \item On 150 hard documents: answer only, \N{label-acc} (\R\N{label-call} a call); quote first, \N{quote-acc} (\R\N{llm-call}). Quoting wins, for about \R\N{quote-extra} more across 5M.
  \end{itemize}
\end{itemize}

\section{Local intelligence}
\begin{itemize}
\item \textbf{Everything except the LLM runs on CPU:} a pretrained layout model (DiT) with a classifier trained in seconds; a text model over 3 to 5 letter pieces (survives OCR typos); checksummed Indian IDs; the address rule, page splitter and masker.
\item \textbf{Every model is calibrated,} so a reported 95\% is right 95\% of the time. Together they settle \N{no-llm} of documents before any LLM call.
\item \textbf{What leaves our machine:} only the LLM call, for \N{c-llm-share} of documents. It sends text, never page images, and we mask IDs and contact details first; names are not masked yet (see Limitations).
\end{itemize}

\section{Limitations}
\begin{itemize}
\item \textbf{Accuracy is on synthetic documents.} IDs and marksheets follow official designs but were not checked against real copies; bank statements are the only outside source tested.
\item \textbf{The masker misses names.} On a public Indian PII set it removes PAN, licence, email and UPI \N{m-pan}; Aadhaar \N{m-aadhaar}; phone \N{m-phone}; date of birth \N{m-dob}.
\item \textbf{A real run needs a labelled seed:} the LLM labels about 5,000 documents; people check only where it disagrees with our models (about 600).
\end{itemize}

\section{Next steps}
\begin{itemize}
\item \textbf{A name masker.}
  \begin{itemize}
  \item \lab{Why:} names are the one personal detail the LLM still sees.
  \item \lab{Why not yet:} it needs a trained model for Indian names; patterns cannot catch them.
  \end{itemize}
\item \textbf{A small fine-tuned text model (LoRA) for L2.}
  \begin{itemize}
  \item \lab{Why:} it reads meaning, so fewer documents reach the LLM and people.
  \item \lab{Why not yet:} it needs labelled real documents; on synthetic data the current model already settles \N{no-llm}, so a gain is unmeasurable.
  \end{itemize}
\item \textbf{Conformal prediction on critical classes.}
  \begin{itemize}
  \item \lab{Why:} it sets the critical-class threshold from labelled data so that recall of 0.90 or more is guaranteed, not just observed on our test sets.
  \item \lab{Why not yet:} the guarantee holds only for documents like the ones it was calibrated on. Ours are synthetic; the real run's labelled seed is the right set.
  \end{itemize}
\item \textbf{A vision LLM for scans with no readable text.}
  \begin{itemize}
  \item \lab{Why:} these are the documents most likely to reach a person today.
  \item \lab{Why not yet:} a page image cannot be masked like text, so full ID numbers and photos would reach the LLM.
  \end{itemize}
\item \textbf{More outside document types for the splitter.}
  \begin{itemize}
  \item \lab{Why:} bank statements were the only outside type tested.
  \item \lab{Why not yet:} no safe public Indian KYC, deed or marksheet sets exist; search hits were real people's documents.
  \end{itemize}
\end{itemize}
